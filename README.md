# GFS &amp; HDFS — Big Data Analysis, Class Test 1 study guide

A single self-contained HTML study guide for **Distributed File Systems (GFS &amp; HDFS)** — Chapter 3 of a
Big Data Analysis / Data Engineering course.

**▶ Live site:** https://shinzuu.github.io/bda-gfs-hdfs/

## What's inside
- **5 drawable SVG diagrams** — HDFS cluster architecture, write pipeline, read path, rack-aware replication, and High Availability.
- **"10 must-knows"**, high-yield fact cards, a numbers table, and a one-line glossary.
- **Self-test** — the chapter's short questions (SQ3.1–3.14) as click-to-reveal cards.
- Light/dark theme, mobile-friendly, and a print-to-PDF mode (auto-expands all answers).

No build step, no dependencies — one `index.html` you can open locally or host anywhere.
